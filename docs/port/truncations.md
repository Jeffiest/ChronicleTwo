# Pointer truncations

Generated by `scripts/port/truncations.py` from the compile commands, `port_overrides.txt` and the symbols of `port/build/pc/darkchronicle`; do not
edit by hand. Regenerate with `tools/kazarov/bin/kazarov shell python3 scripts/port/truncations.py --build port/build/pc --out docs/port/truncations.md`.

A row is one cast of a pointer to an integer narrower than the pointer (or a full-width integer an implicit
narrowing then truncates) in `ps2/src`, `port/src` and their headers, grouped by the unit it is read in. The
host's pointers are 64-bit, so a **round-trip** row whose value is read as a pointer again is a fault waiting
for a run; each one still open is a place where a ps2/src unit truncates.

- **state**: `replaced` when the enclosing function's signature is listed in the build's `port_overrides.txt`
  (a `PORT_OVERRIDE` definition in port/src replaces it, so ps2/src's body is never compiled); `open` otherwise.
- **round-trip**: the value comes back as a pointer (cast back, stored or passed into an int that is cast back
  somewhere, returned from a function whose result is cast back, or an absolute address added to a pointer).
- **resolved**: a round trip whose value only becomes a pointer again in replaced functions.
- **low-bits**: only the low bits are used (masks, modulo, shifts, differences of two truncated pointers,
  tests, comparisons, a pointer field holding a file offset added to a base).
- **escapes**: stored into memory, an aggregate or an unknown callee, and never seen cast back; read by hand.
- **masked**: an address-alias literal (`0x0FFFFFFF`, `0x20000000`) is applied to the value on the way.
- **phase**: for an open round trip, the phase whose work package replaces its function; `not linked` when the
  binary does not define it, `unassigned` when `PHASE_OF` lacks it (`--check` fails); `-` for other rows.

Origin is where the pointer points, where the expression shows it: **image** (a global, a literal, a function),
**stack**, **arena** (an `mgCMemory` buffer, through `Alloc`, `stAlloc64` or its heap and stack fields),
**parameter**, **field**, **global pointer**, **local pointer**, **call**, **this**.
